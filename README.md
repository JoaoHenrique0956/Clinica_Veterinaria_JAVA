# Clínica Veterinária

Este projeto consiste no desenvolvimento de um sistema para gerenciamento de uma clínica veterinária utilizando a linguagem **Java**.

O sistema tem como objetivo facilitar o controle das informações da clínica, permitindo o cadastro e gerenciamento de uma Agenda de Consultas, abrangendo o Animal, e seu respectivo tipo, sintomas e seu Dono.

## Tecnologias utilizadas

* Java
* Programação Orientada a Objetos (POO)

## Objetivo

O projeto foi desenvolvido como atividade acadêmica, com o objetivo de aplicar conceitos de programação em Java e criar uma aplicação para auxiliar na organização de uma clínica veterinária.
